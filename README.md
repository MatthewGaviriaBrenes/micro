# Micro Compiler

Compiler for the Micro programming language.

## Language

Micro is a small programming language described in Chapter 2 of:

Fischer and LeBlanc, *Crafting a Compiler with C*.

## Requirements

- Linux
- GCC
- Make
- x86 environment

## Project Structure

- `src/` — compiler source code
- `tests/` — tests
- `examples/` — example Micro programs
- `docs/` — project documentation

## Compilation

```bash
make
